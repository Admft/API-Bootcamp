# Python: Strings, Numbers, Booleans

```python
name = "Acme Fleet"   # string — text in quotes
count = 10            # integer — whole number
active = True         # boolean — True or False

print(name)
print(count)
print(active)
```

## Rules kids (and SEs) need

- Strings use quotes: `"hello"` or `'hello'`
- Numbers do **not** use quotes: `10`
- Variable names: letters, numbers, underscore — start with a letter
- `print(x)` shows the value of `x`
