Next: List incidents →
{% elif lesson.type == 'lab' and lesson.id == 'postman-get-lab' %}

Lab: List incidents in Postman

  1. Open the List open incidents request in the collection
  2. Set Authorization to Bearer Token using your SOURCE_API_KEY from .env
  3. Confirm query param status=open (or add it)
  4. Send the request — expect 200 and a JSON list under data

Check each item as you finish — this lesson completes when all are done.

Next: Create ticket →
{% elif lesson.type == 'lab' and lesson.id == 'postman-post-lab' %}

Lab: Create ticket + 409

  1. Open the Create ticket request (destination API, port 5002)
  2. Set Bearer auth with DESTINATION_API_KEY
  3. POST a JSON body with external_id, site, description, priority
  4. Expect 201 on first create
  5. Send the same body again — expect 409 Conflict

Check each item as you finish — this lesson completes when all are done.
